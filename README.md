# Focus App

Web app personale di produttività: to-do list + Pomodoro timer.

## Come aprire l'app
1. Apri la cartella del progetto in VS Code.
2. Installa l'estensione **Live Server** (di Ritwick Dey), se non l'hai già.
3. Clic destro su `index.html` → **Open with Live Server**.
4. Il browser si apre sull'app e si ricarica da solo a ogni modifica salvata.

Dettagli su decisioni e avanzamento in [PROGETTO.md](PROGETTO.md).
